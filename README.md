# 🚀 Day 13 – Setting Up an Express Server & Building CRUD APIs

Welcome to **Day 13 of my Coding Challenge!** 🎯

Today, I focused on backend development by setting up an Express.js server and learning how to build RESTful APIs to perform CRUD operations.

## 📌 Project Overview

This project demonstrates the fundamentals of building a backend server using **Node.js and Express.js**. It focuses on handling HTTP requests, defining API routes, and implementing CRUD operations.

🔗 **GitHub Repository:** [express-project](https://github.com/harinigokulnath1624/express-project)

## 🛠️ Technologies Used

- **Node.js** – JavaScript runtime for backend development.
- **Express.js** – Web framework for building servers and APIs.
- **JavaScript** – Implementing server-side logic.
- **REST API** – Structuring endpoints to handle client requests.

## ✨ Key Features

- Set up an Express.js server.
- Configure routes to handle HTTP requests.
- Build RESTful API endpoints.
- Implement CRUD operations:
  - **Create** – Add new data.
  - **Read** – Retrieve existing data.
  - **Update** – Modify existing data.
  - **Delete** – Remove data.
- Handle client requests and send appropriate responses.

## 🔄 Understanding CRUD Operations

| Operation | HTTP Method | Purpose |
|---|---|---|
| Create | `POST` | Add new data |
| Read | `GET` | Retrieve data |
| Update | `PUT` / `PATCH` | Update existing data |
| Delete | `DELETE` | Remove data |

## 📚 What I Learned

- How to initialize and configure an Express.js server.
- How Express routes handle incoming HTTP requests.
- How different HTTP methods support CRUD operations.
- How to structure RESTful API endpoints.
- How frontend applications communicate with backend APIs.
- How to strengthen my backend development fundamentals.

## 💻 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- [Git](https://git-scm.com/)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/harinigokulnath1624/express-project.git
```

**2. Navigate to the project directory**

```bash
cd express-project
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the server**

Use the appropriate command configured in your project's `package.json`, or run the main server file with Node.js.

For example:

```bash
node index.js
```

> **Note:** Replace `index.js` with your actual server filename if it is different.
